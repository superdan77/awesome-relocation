# Contribution Guidelines

Thanks for helping keep this list accurate.

## Adding an entry

- The resource must help with the move itself: finding a sponsoring employer, or settling in once you arrive. Visa rules and founder programmes belong in the two sibling lists linked under Related Lists.
- Link to the official site or the canonical repository, not a blog post, an affiliate page or a third-party review.
- Check the link resolves before you open the pull request. Dead sites and abandoned projects are removed.
- Use this format and keep the section in alphabetical order:

  `- [Name](https://link) - One sentence ending in a period.`

- Do not start the description with the name of the entry itself.
- Write plain English. No marketing copy, no superlatives, no claims the linked page does not make.
- One resource per pull request, unless the pull request updates a whole section.

## Updating an entry

Services change, move and shut down. If a link broke, a site changed what it does, or a description is no longer accurate, open a pull request with the link that shows the change.
